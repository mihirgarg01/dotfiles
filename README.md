# Dotfiles Usage

- Clone the repo in ~ (user should not be root)
- Cd into the repo `cd dotfiles`
- Give the install script merissions: `chmox +x install.sh`
- Run the installer: `./install.sh`

- `logid.cfg` is for the logitech mx master 3
- Install using `yay -S logiops`
- Use `sudo logid -v` to find the name of the mouse
